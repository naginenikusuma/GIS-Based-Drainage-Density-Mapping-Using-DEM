# GIS-Based Drainage Density Mapping Using DEM

## Project Overview

This project uses GIS and Digital Elevation Model (DEM) data to
extract drainage networks and prepare a drainage density map
for Vellore District, Tamil Nadu, India.

## Objectives

- Process DEM data using ArcGIS Pro
- Generate flow direction and flow accumulation
- Extract drainage networks
- Calculate drainage density
- Prepare the final drainage density map
- Analyze spatial variation of drainage density

## Software Used

- ArcGIS Pro
- Spatial Analyst
- ModelBuilder

## Methodology

1. DEM datasets were collected for the study area.
2. DEM tiles were mosaicked into a continuous raster.
3. Fill tool was used to remove sinks.
4. Flow Direction was generated.
5. Flow Accumulation was calculated.
6. Streams were extracted using a suitable threshold.
7. Drainage network was generated.
8. Drainage density was calculated.
9. Final drainage density map was prepared.

## Results

The final drainage density map shows the spatial
variation of drainage characteristics across the study area.
